    Supported syntax and current interpreter assumptions
    

      
SyntaxImplemented behavior

      
        
(•o•?)Read the next line from Program input and save it as the latest input value.

        
:# Name = expressionAssign a value to a variable. Example: :# Input = :&.

        
:&Use the most recently read input value.

        
(•o•) expressionPrint a quoted string or the evaluated value of an expression.

        
:) / :(True / false.

        
=/ conditionStart an if branch.

        
 =\ conditionElse-if branch. (Leading spaces are ignored.)

        
=|Else branch.

        
=OClose the current conditional or loop block.

        
:SStart a repeating loop, closed by =O. A safety limit prevents runaway programs.

        
>:3Generate a random integer from 0 through 99; may be used as an expression or printed.

        
=, ==, !=, >, <, >=, <=Comparison operators accepted in conditions.
