# Expression-Interpreter
An interpreter for my Esolang: Expression

This is an emoticon based esolang where you use faces to code.

Esolang wiki:
https://esolangs.org/wiki/Expression

Use here:
https://inventor702.github.io/Expression-Interpreter/

Syntax:

 ":)"
 True

 ":("
 False

 "=/"
 if

 "=|"
 Else

 "=\\"
 Else if

 "=O"
 End

 "(•o•?)"
 Get input

 "(•o•)"
 Print text

 ":#"
 Establishes variable

 ":&"
 Get input variable

">:3"
 Random Number

 ":S"
 Loop
